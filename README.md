# 2059

A near-future cyberpunk roguelike boss-farming RPG (originally built on Replit). See `replit.md` for the full design and architecture notes.

## Running locally

Requires Node.js 20+.

```bash
npm install
npm run dev      # dev server on http://localhost:5000
npm run build    # production build into dist/
npm start        # run the production build
```

The `attached_assets/` folder holds reference screenshots and notes from development.

⸻

2) Wire the pool into your existing loot system

Open:

client/src/lib/combat/loot.ts

A) Add this import at the top (with the other imports)

import { ITEMS_2059 } from "./items2059";

B) Find this line

export const ITEM_POOLS: Record<ItemRarity, Item[]> = generateItemPools();

Replace it with this:

export const ITEM_POOLS: Record<ItemRarity, Item[]> = {
  common: ITEMS_2059.filter(i => i.rarity === "common"),
  uncommon: ITEMS_2059.filter(i => i.rarity === "uncommon"),
  rare: ITEMS_2059.filter(i => i.rarity === "rare"),
  epic: ITEMS_2059.filter(i => i.rarity === "epic"),
  legendary: ITEMS_2059.filter(i => i.rarity === "legendary"),
};

Save.

Run.

Loot will now pull from your 2059 pool.

⸻

3) How to “fill out” the pool properly (your workflow)

When you add new items, do it like this:
	1.	Pick a corp tag for the name: [KIZUNA] [HELIX] [TIANXIA] [CROWN] [VOLKOV] [PARSU] [IOA] [PIRATE]
	2.	Pick slot + rarity
	3.	Use the placeholder scaling so balance stays stable:
	•	common x1
	•	uncommon x2
	•	rare x3
	•	epic x5
	•	legendary x8
	4.	Give it an icon you like.
	5.	Keep id unique.

That’s it.
